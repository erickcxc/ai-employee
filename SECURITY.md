# Security

## Reporting a vulnerability

Please report security issues privately through GitHub's "Report a vulnerability" button on this
repository (Security tab). Do not open a public issue.

Include what you found, how to reproduce it and what an attacker could do with it. You will get an
acknowledgement within three business days and a fix or a plan within thirty.

## Scope

Everything in this repository. The sample business, Brightwater Plumbing, and all its data are
synthetic: no real customer data exists here.
